# SmokeDev

I build open-source agent systems that can remember, coordinate, speak, and prove
what they did. These are the three projects at the center of that work.

## Flagship systems

### 01 / [TaskChad OS](https://github.com/TheSmokeDev/taskchad-os)

[![Stars](https://img.shields.io/github/stars/TheSmokeDev/taskchad-os?style=social)](https://github.com/TheSmokeDev/taskchad-os/stargazers)
[![Release](https://img.shields.io/github/v/release/TheSmokeDev/taskchad-os?sort=semver)](https://github.com/TheSmokeDev/taskchad-os/releases/latest)

An identity-first cognitive agent operating system: persistent memory,
multi-channel ingress, Operating Room orchestration, approval-aware delegation,
and desktop control surfaces. TaskChad OS is where agents become a durable
operating environment instead of another disposable chat window.

**Explore:** [architecture and source](https://github.com/TheSmokeDev/taskchad-os) ·
[latest release](https://github.com/TheSmokeDev/taskchad-os/releases/latest)

### 02 / [geo-skills](https://github.com/TheSmokeDev/geo-skills)

[![Stars](https://img.shields.io/github/stars/TheSmokeDev/geo-skills?style=social)](https://github.com/TheSmokeDev/geo-skills/stargazers)
[![PyPI](https://img.shields.io/pypi/v/geoskills)](https://pypi.org/project/geoskills/)
[![CI](https://github.com/TheSmokeDev/geo-skills/actions/workflows/ci.yml/badge.svg)](https://github.com/TheSmokeDev/geo-skills/actions/workflows/ci.yml)

Twenty-nine free Agent Skills plus an installable CLI for Generative Engine
Optimization, AI-search visibility, citability, crawler access, live-data prompt
packs, and owner-intent mapping. Built for Claude Code, Codex, and other agents
that read `SKILL.md`.

```bash
python -m pip install geoskills
```

### 03 / [Hermes Talk](https://github.com/TheSmokeDev/hermes-talk)

[![Stars](https://img.shields.io/github/stars/TheSmokeDev/hermes-talk?style=social)](https://github.com/TheSmokeDev/hermes-talk/stargazers)
[![PyPI](https://img.shields.io/pypi/v/hermes-talk)](https://pypi.org/project/hermes-talk/)
[![CI](https://github.com/TheSmokeDev/hermes-talk/actions/workflows/ci.yml/badge.svg)](https://github.com/TheSmokeDev/hermes-talk/actions/workflows/ci.yml)

Realtime voice as an orchestrator for Hermes Agent. Talk naturally while Hermes
uses tools, searches memory, delegates concurrent work, accepts interruption,
and reports completed runs back out loud across terminal, dashboard, and Discord
surfaces.

```bash
hermes plugins install TheSmokeDev/hermes-talk --enable
python -m pip install "hermes-talk[audio]"
hermes talk
```

## What connects them

```text
TaskChad OS   → identity, memory, orchestration, control plane
geo-skills    → GEO research, AI-search visibility, citation growth
Hermes Talk  → realtime voice, tool use, delegation, operator feedback
```

Different surfaces, same doctrine: persistent context, inspectable commands,
approval boundaries, deterministic gates, and receipts that distinguish local
output from pushed, deployed, indexed, or cited reality.
